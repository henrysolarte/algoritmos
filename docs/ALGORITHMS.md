# Algoritmos de Sorting

Implementación de algoritmos de ordenamiento en JavaScript.

## Algoritmos Básicos

### Bubble Sort
- Complejidad: O(n²)
- Espacio: O(1)
- Estable: Sí
- En-lugar: Sí

### Selection Sort
- Complejidad: O(n²)
- Espacio: O(1)
- Estable: No
- En-lugar: Sí

### Insertion Sort
- Complejidad: O(n²)
- Espacio: O(1)
- Estable: Sí
- En-lugar: Sí

## Algoritmos Avanzados

### Quick Sort
- Complejidad: O(n log n) promedio, O(n²) peor caso
- Espacio: O(log n)
- Estable: No
- En-lugar: Sí

### Merge Sort
- Complejidad: O(n log n)
- Espacio: O(n)
- Estable: Sí
- En-lugar: No

### Heap Sort
- Complejidad: O(n log n)
- Espacio: O(1)
- Estable: No
- En-lugar: Sí
